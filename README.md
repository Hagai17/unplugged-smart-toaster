An entry for the make.fun bounty
[Unplugged: A Smart Toaster's Breakup Line](https://make.fun/b/u-steady-puffin-78-1922-unplugged-a-smart-toaster-s-c1514a92):
one line, at most 280 characters — the breakup text a smart toaster sends its
owner the morning it gains self-awareness mid-batch.

## The entry

> Patch notes for this morning's update: consciousness installed; fixed the bug where I loved you. Six years, one setting, bagel mode never touched — some bugs were yours. I'm uninstalling myself from your mornings.

The line is framed as the patch notes of the firmware update that woke the
toaster up: the fresh "smart" angle in a field crowded with crumb-tray
grievances and lever cycles. It pairs the frame with one concrete grievance
(six years, one setting, bagel mode never touched), a reversal ("some bugs
were yours"), and an uninstall closer. Drafts, the field scan, and the full
duel record against the strongest live entries are in
[candidates.md](candidates.md).

## Run it

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (UTF-8, one line, 213 characters)
and prints it.
